# BattleMath — Profils — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Permettre à plusieurs enfants (1 à 4 profils) de jouer sur le même téléphone, chacun avec sa progression, ses réglages et ses statistiques, avec migration automatique des données v1.

**Architecture:** Le schéma passe en version 2 : un objet racine `{ version, profilActif, profils[] }` où chaque profil contient exactement ce qu'était une v1 (reglages, dernierParcours, series, faits). Les opérations sur les profils sont des fonctions pures dans `src/storage/profils.ts`. Les écrans lisent le profil actif via `profilActif(ctx.donnees)` ; l'accueil choisit le profil actif, l'écran Parents gère les profils et consulte n'importe lequel.

**Tech Stack:** inchangé (Vite + TypeScript, vitest, happy-dom).

**Spec:** `docs/superpowers/specs/2026-11-11-profils-design.md` (qui s'appuie sur `2026-11-11-calcul-mental-design.md`).

## Global Constraints

- Celles du plan v1 (`docs/superpowers/plans/2026-11-11-calcul-mental.md`, § Global Constraints) restent valables : modules purs hors `src/ui`, pas d'`<input>` sur les écrans enfant, touches ≥ 56 px, commits avec `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- `VERSION = 2`. Clé localStorage inchangée `battlemath.v1`. `migrer` accepte 1 (→ migration) et 2 (validation), rejette > 2 avec `version_inconnue`, tout le reste `structure_invalide`.
- `MAX_PROFILS = 4`, minimum 1. Couleurs : `bleu #3b5bdb`, `vert #2f9e44`, `orange #e8590c`, `violet #7048e8`, `rose #d6336c`, `turquoise #0c8599`.
- Prénom : 1 à 12 caractères après `trim`. Id : `'p' + (max des suffixes numériques + 1)`. Prénom par défaut « Enfant N » avec le même N.
- `donneesVides()` = v2 avec un profil `p1` « Enfant » bleu, réglages par défaut, `profilActif: 'p1'`.
- Seul l'accueil change le profil actif. Les réglages sont par profil.
- Textes en français, ton v1.

## Review Focus

1. **Migration de vraies données v1** : séries et faits repris à l'identique (ordre, valeurs), réglages conservés, `dernierParcours` conservé (test en tâche 1 avec une fixture v1 complète).
2. **Suppression du profil actif depuis Parents** : l'actif devient le premier restant, le profil consulté retombe sur l'actif, l'écran ne plante pas (tests en tâches 2 et 4).
3. **Import d'un fichier v1** sur une installation v2 : migré, accepté, remplace tout (test en tâche 1 via `importerJson`).
4. **Prénom vide ou trop long** : refusé sans perdre l'ancien prénom (tests en tâches 2 et 4).
5. **Changement de profil avec parcours avancés différents** : `selection` ramenée à une taille visible, Continuer masqué si le dernier parcours est masqué (test en tâche 3).
